# Brain-Tumor-Detection-CNN
Deep learning-based MRI image classification system using CNN for multi-class brain tumor detection. Includes image preprocessing, normalization, model training, and a Streamlit-based interface for real-time prediction.
This project is a deep learning-based MRI brain tumor classification system developed using Python, TensorFlow, Keras, OpenCV, and Streamlit. The model classifies MRI brain images into four categories: glioma, meningioma, pituitary tumor, and no tumor.

A Convolutional Neural Network (CNN) was trained on MRI image datasets and achieved approximately 95% test accuracy.
